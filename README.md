Brief description of each program

1 - Basic Single Inheritance – Demonstrates how a derived class inherits members from a base class.

2 - Protected Member Access – Demonstrates how a derived class can access a protected member of the base class.

3 - Public versus Private Inheritance – Shows the difference between public and private inheritance and how they affect member accessibility.

4 - Multilevel Inheritance – Demonstrates inheritance through three levels: Person → Employee → Manager.

5 - Hierarchical Inheritance – Demonstrates multiple derived classes (Car and Bike) inheriting from one base class (Vehicle).

6 - Multiple Inheritance – Demonstrates a class inheriting from two base classes, Academic and Sports.

7 - Resolving Multiple-Inheritance Ambiguity – Demonstrates how the scope-resolution operator is used when two base classes have functions with the same name.

8 - Constructor and Destructor Order – Demonstrates the order in which base and derived class constructors and destructors are executed.

9 - Parameterized Base Constructor – Demonstrates how a derived-class constructor initializes a parameterized base class.

10 - Function Overriding – Demonstrates overriding a virtual function in derived classes using virtual and override.

11 - Abstract Class – Demonstrates an abstract class using a pure virtual function.

12 - Virtual Base Class and Diamond Inheritance – Demonstrates how a virtual base class prevents duplicate base-class objects in diamond inheritance.

13 - Friend Class – Demonstrates how a friend class can access private members of another class.

14 - Nested Class – Demonstrates how a class can be defined inside another class.

15 - Mini-Project: Vehicle Rental System – Demonstrates an inheritance-based vehicle rental system using cars and bikes.

16 - Mini-Project: Employee Payroll System – Demonstrates an employee salary system using abstract classes, inheritance, and function overriding.
